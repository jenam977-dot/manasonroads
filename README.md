# MANASONROADS Hugo Site

Cinematic motorcycle travel website migrated to Hugo with blog.

## Commands

```bash
# Local dev server
hugo server

# Production build
hugo

# New blog post
hugo new content blog/my-post.md
```

## Structure

- content/ - Markdown content
- layouts/ - Hugo templates
- assets/ - Source assets
- static/ - Static files

## Deployment

Compatible with GitHub Pages, Netlify, Cloudflare Pages, Vercel.
